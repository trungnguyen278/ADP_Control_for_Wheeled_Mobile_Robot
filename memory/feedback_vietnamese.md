Mọi báo cáo và luận văn đều phải viết bằng tiếng Việt có dấu.

**Why:** User explicitly corrected when initial documents were written without Vietnamese diacritics — this is a hard requirement for all academic deliverables submitted to advisor.

**How to apply:** Any LaTeX document (thesis, reports, summaries) must use T5 fontenc for Vietnamese encoding and all content must be in proper Vietnamese with diacritics. Never default to English or unaccented Vietnamese for these documents.
